🏗️ ARCHITECTURE AT A GLANCE
───────────────────────────────────────────────────────────────────────────────

COMPRESSION PIPELINE:
  Input File
    ↓
  FileReader (read all data)
    ↓
  Tokenizer (split words from spaces/punctuation)
    ↓
  FrequencyAnalyzer (count word occurrences)
    ↓
  CandidateGenerator (filter: frequency >= 2)
    ↓
  SavingsCalculator (check: savings > 0?)
    ↓
  Dictionary (store profitable words as tokens)
    ↓
  +─ Dictionary Header (#0:word1\n#1:word2\n...)
  │
  ├─ Delimiter (===END_DICT===\n)
  │
  └─ Compressed Body (words → tokens, rest unchanged)
    ↓
  Output .CMP File

DECOMPRESSION PIPELINE:
  Compressed .CMP File
    ↓
  FileReader (read all data)
    ↓
  DictionaryParser (extract header until ===END_DICT===)
    ↓
  Dictionary (build token → word mapping)
    ↓
  TokenScanner (find #N patterns in body)
    ↓
  TokenExpander (replace tokens with original words)
    ↓
  Output Restored File (identical to original)

📈 KEY ALGORITHM
───────────────────────────────────────────────────────────────────────────────

PROFIT CALCULATION:
  OriginalCost = Frequency × WordLength
  
  ReplacementCost = (Frequency × TokenLength) 
                  + DictionaryEntryLength
  
  NetSaving = OriginalCost - ReplacementCost
  
  DECISION: Include if NetSaving > 0

EXAMPLE - Word: "software" (appears 3 times):
  Original:     3 × 8 = 24 bytes
  Token cost:   3 × 2 = 6 bytes
  Dict entry:   "#0:software\n" = 12 bytes
  Total:        6 + 12 = 18 bytes
  Saving:       24 - 18 = 6 bytes ✓ PROFITABLE

💡 KEY DESIGN RULES
───────────────────────────────────────────────────────────────────────────────

Rule 1: Profit-Based Compression
  "Do not replace words merely because they repeat.
   Replace only when savings are positive."

Rule 2: File Format
  "Dictionary first, ===END_DICT===, then body"

Rule 3: Decompression
  "Parse dictionary, build token→word map, expand tokens"

Rule 4: Correctness
  "Decompress(Compress(x)) == x always"

🔍 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Build fails:
  → Check C++17 compiler: g++ --version
  → Check Makefile settings
  → Try: g++ -std=c++17 main.cpp compressor.cpp -o compressor

Round-trip fails:
  → Check for last newline differences
  → Run: diff -u original.txt restored.txt
  → Check TESTING.md for similar issues

Compression not effective:
  → Check if words repeat (frequency >= 2)
  → Small files may have negative compression
  → See TESTING.md for detailed analysis

Cannot find executable:
  → Check current directory: ls -la compressor
  → Check Makefile target: make help
  → Verify build completed
